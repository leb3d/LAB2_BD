# Практична робота №2 — Schoolsearch

**Дисципліна:** Бази даних  
**Університет:** Харківський національний університет імені В. Н. Каразіна  
**Група:** КС-23  
**Мова програмування:** Java

## Опис роботи

У практичній роботі №2 програму `Schoolsearch` адаптовано для роботи з двома окремими файлами даних. Програма виконує пошук учнів і викладачів, дозволяє додавати, змінювати та видаляти записи, а також вимірює час виконання операцій.

Програму реалізовано без СКБД і сторонніх бібліотек.

## Вхідні дані

Використано файли, надані для перевірки 04.11.2026:

| Файл | Вміст | Кількість записів |
|---|---|---:|
| `list.txt` | Прізвище та ім'я учня, клас, кабінет, автобус | 458 |
| `teachers.txt` | Прізвище та ім'я викладача, кабінет | 542 |

У файлі `teachers.txt` міститься **127 унікальних пар** «прізвище + ім'я». Вхідні файли залишено без змін: порядок і вміст рядків збережено.

**Особливість даних:** одному кабінету відповідає кілька викладачів. Через це результати пошуку викладача за кабінетом не завжди збігаються з результатами ЛАБ1.

## Запуск у Windows

1. Розпакувати архів і відкрити папку проєкту в IntelliJ IDEA.
2. Переконатися, що JDK встановлено, а команди `javac` і `java` доступні в терміналі.
3. Відкрити вкладку **Terminal** у кореневій папці проєкту.
4. Виконати команду:

   ```powershell
   .\run_windows.bat
   ```

5. Вводити команди програми по одній. Для завершення ввести `Q`, а після закриття програми натиснути будь-яку клавішу.

Файл `run_windows.bat` налаштовує виведення в консоль Windows-1251. Вхідні текстові файли читаються програмою у UTF-8.

### Запуск без BAT-файлу

У терміналі з кореневої папки проєкту:

```powershell
javac -encoding UTF-8 -d out src\Schoolsearch.java
java -Dfile.encoding=UTF-8 -cp out Schoolsearch
```

## Команди для перевірки

| Команда | Дія |
|---|---|
| `STATS` | Показати кількість записів |
| `S: SCHOENECKER` | Знайти учня та пов'язаних за кабінетом викладачів |
| `S: SCHOENECKER B` | Показати автобус учня |
| `T: FALKER` | Знайти учнів за прізвищем викладача |
| `C: 104` | Знайти учнів за номером кабінету |
| `B: 51` | Знайти учнів за автобусним маршрутом |
| `G: 3` | Знайти учнів за класом |
| `C: 104 T` | Знайти викладачів за кабінетом |
| `G: 3 T` | Знайти викладачів за класом учнів |

### Перевірка зміни записів

Команди вводяться послідовно:

```text
A: TEST,USER,3,104,51
U: 459,Bus,55
S: TEST B
D: 459
S: TEST
Q
```

На початкових даних після додавання новий запис отримує ID `459`. Після зміни маршрут має бути `55`, після видалення пошук `S: TEST` не повинен повертати запис.

## Результати тестування

Результати перевірки на наданих файлах збережено в папці `evidence/`:

- `official_queries.csv` — результати пошукових запитів;
- `official_query_examples.txt` — приклади виводу;
- `official_crud_export.txt` — перевірка додавання, зміни, видалення та експорту;
- `data_verification.txt` — перевірка вхідних файлів.

Час виконання в цих файлах отримано в середовищі **OpenJDK 21 / Linux**. Це не вимірювання на комп'ютері студента. Результати окремого запуску у Windows наведено у звіті та відповідному журналі в папці `evidence/` (якщо він входить до комплекту).
