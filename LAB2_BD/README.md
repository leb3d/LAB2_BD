## Дані
`list.txt` і `teachers.txt` — точні копії файлів, наданих для перевірки 04.11.2026 (без зміни порядку або вмісту рядків).

- Кожному кабінету відповідає багато викладачів; тому результати запитів, що відновлюють викладача за номером кабінету, не можуть бути один-в-один еквівалентними ЛАБ1.

## Запуск у Windows (IntelliJ IDEA — вкладка Terminal)
1. Розпакуйте проєкт і відкрийте його папку в IntelliJ.
2. Переконайтесь, що встановлений JDK і команди `javac`, `java` доступні з терміналу.
3. У PowerShell з кореня проєкту: ` .\run_windows.bat `
4. Файл налаштовує вивід у Windows-1251, як перевірено у вашому терміналі. Вхідні файли Java читає як UTF-8.
5. Введіть команди окремими рядками; завершення `Q`. Після завершення натисніть будь-яку клавішу для виходу із BAT.

Для запуску без BAT у кореневій папці:
```powershell
javac -encoding UTF-8 -d out src\Schoolsearch.java
java -Dfile.encoding=UTF-8 -cp out Schoolsearch
```

## Перевірка
Команди `S: SCHOENECKER`, `S: SCHOENECKER B`, `T: FALKER`, `C: 104`, `B: 51`, `G: 3`, `C: 104 T`, `G: 3 T`, `STATS`. Зміна: `A: TEST,USER,3,104,51`, `U: 459,Bus,55`, `S: TEST B`, `D: 459`. Завершення: `Q`.

Результати реального запуску Java з цими файлами — `evidence/official_queries.csv`, `evidence/official_query_examples.txt`, `evidence/official_crud_export.txt`, `evidence/data_verification.txt`. Час зафіксовано в середовищі OpenJDK 21 / Linux і не є вимірюванням на вашому ПК.
